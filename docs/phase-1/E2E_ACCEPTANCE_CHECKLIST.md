# MP Phase-1 Sales acceptance checklist

1. Create a Query from **Sales & Queries → Create Query** and confirm it appears as **Awaiting Assignment**.
2. Open **Assignment Desk**, assign it to an active Sales employee and confirm a review task is created.
3. Open the Query 360 record and log a call/email/WhatsApp outcome with a next follow-up.
4. Open **Itinerary & Costings**, start a linked Costing, save a quotation and confirm a new Costing version and commercials appear on Query 360.
5. Move the Query to **Quotation Sent** and confirm the +3 day follow-up task is created.
6. Inspect the same Query in Dashboard, Tracker, Pipeline and Follow-up Desk; filters should change every counter/list together.
7. Mark a test Query **Lost** and verify a reason is mandatory and open Query tasks close.
8. Mark a different test Query **Won**, verify the celebration and accept the generated item from **Won Query Intake**.
9. Review **Sales Performance**, **My Day**, advisor SOD workload and **Data Readiness**.

The sequence above exercises the complete Phase-1 Sales flow without requiring a database migration or a full Operations module.
